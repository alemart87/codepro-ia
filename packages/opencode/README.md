## 🚀 Instalación

```bash
npm install -g codepro-ia
```

O con bun:

```bash
bun install -g codepro-ia
```

## 💻 Uso

```bash
codepro-ia
```

## ✨ Características

- 🤖 **Multi-proveedor AI**: Soporta OpenAI, Anthropic, Google, xAI, Groq, y más
- 🎨 **TUI Profesional**: Interfaz de terminal interactiva y moderna
- 🦒 **Mascota Jirafa**: ¡Porque ser profesional no significa ser aburrido!
- 🔧 **Extensible**: Sistema de plugins para extender funcionalidades
- 🌐 **MCP Support**: Compatible con Model Context Protocol

## 🔧 Configuración

Configura tu API key según el proveedor:

```bash
export OPENAI_API_KEY="tu-api-key"
# o
export ANTHROPIC_API_KEY="tu-api-key"
```
